⚠️ 关于锁屏状态

  • 锁屏问题：如果 Windows Server 处于锁屏状态，截图可能显示黑屏
  • 原因：系统锁屏时会限制对活动桌面的访问
  • 解决方案：
    • 保持远程桌面连接处于活动状态
    • 配置服务器不自动锁屏（组策略或电源设置）
    • 使用计划任务定期"唤醒"屏幕
  • 注意：系统会自动检测锁屏状态并显示警告
