# 远程桌面控制测试客户端使用说明

## 功能概述

这是一个基于 WebSocket 的远程桌面控制测试客户端，可以用于：
- 实时查看远程服务器屏幕
- 远程控制鼠标和键盘
- 测试远程控制功能

## 访问方式

1. 启动 FastAPI 服务器后，访问：`http://localhost:8081/api/remote/`
2. 页面会自动加载远程桌面控制界面

## 使用方法

### 1. 连接服务器
- 点击"连接"按钮建立 WebSocket 连接
- 连接成功后，状态指示器会变为绿色

### 2. 查看远程屏幕
- 连接成功后，点击"开始自动截图"按钮
- 系统会以约 10 FPS 的速度自动刷新屏幕
- 也可以点击"手动截图"按钮进行单次截图

### 3. 控制远程桌面

#### 鼠标操作
- **左键点击**：在屏幕上点击即可
- **右键点击**：在屏幕上右键点击
- **鼠标移动**：移动鼠标即可控制远程鼠标
- **滚轮**：在屏幕上滚动鼠标滚轮

#### 键盘操作
- **普通输入**：点击屏幕后，直接输入文字
- **快捷键支持**：
  - `Ctrl + C`：复制
  - `Ctrl + V`：粘贴
  - `Ctrl + X`：剪切
  - `Ctrl + A`：全选
  - `Ctrl + Z`：撤销
  - `Ctrl + S`：保存

### 4. 监控信息
- **连接状态**：显示当前连接状态
- **FPS**：显示当前帧率
- **鼠标位置**：显示当前鼠标在远程屏幕上的坐标
- **接收帧数**：显示已接收的截图帧数
- **日志**：显示操作日志和连接状态

## 注意事项

1. **安全警告**：此功能会完全控制服务器桌面，请仅在测试环境使用
2. **性能影响**：自动截图会占用一定的 CPU 和网络资源
3. **防火墙**：确保 WebSocket 端口（8081）未被防火墙阻止
4. **权限**：某些操作可能需要管理员权限

## 技术实现

- **前端**：HTML5 + JavaScript + WebSocket
- **后端**：FastAPI + WebSocket + PIL (截图) + PyAutoGUI (控制)
- **通信协议**：WebSocket 二进制传输（截图）和文本传输（控制命令）

## 故障排除

### 无法连接
- 检查服务器是否正在运行
- 检查端口是否正确（默认 8081）
- 检查防火墙设置

### 截图不显示
- 检查 WebSocket 连接状态
- 查看浏览器控制台是否有错误
- 尝试手动截图

### 控制无响应
- 检查连接状态
- 查看日志中的错误信息
- 确认服务器端 pyautogui 库正常工作
